
## SERVD - AI Recipe Platform 🍳✨
> Full-stack AI-powered recipe generation and pantry management platform.
> **Made with ❤️ Romsha Wadhwa**

---

## 📌 Overview

SERVD is an AI cooking assistant platform that allows users to:
- **Scan & Manage Pantry**: Keep track of ingredients in your fridge/pantry with smart image scanning.
- **Generate AI Recipes**: Turn leftover pantry ingredients into custom recipes generated by Google Gemini AI.
- **Search & Discover Recipes**: Access thousands of global recipes powered by TheMealDB API.
- **Export Digital Cookbook**: Save favorite recipes and download full recipe PDFs.
- **Rate Limits & Subscription Tiers**: Arcjet rate limiting for Free (5 AI generations/month) and Pro tiers.

---

## 🛠️ Tech Stack

### Frontend
- **Framework**: Next.js 16 (App Router with Server Actions)
- **Language**: React 19 / JavaScript (ES6+)
- **Styling**: Tailwind CSS v4 + Shadcn UI (Neobrutalism theme)
- **Authentication**: Clerk Auth (`@clerk/nextjs`)
- **AI Engine**: Google Gemini AI (`@google/generative-ai`)
- **Security & Rate Limiting**: Arcjet (`@arcjet/next`)
- **PDF Generation**: `@react-pdf/renderer`
- **Icons**: Lucide React

### Backend
- **Headless CMS**: Strapi v5
- **Database**: Serverless PostgreSQL (Neon DB) / PostgreSQL
- **Media Storage**: Cloudinary / Local Provider
- **Image Search**: Unsplash API

## ⚡ Quick Start & Installation

### 1. Prerequisite Requirements
- **Node.js**: `v20.0.0` or higher
- **npm**: `v10.0.0` or higher

### 2. Clone / Setup Workspace
Run commands directly inside the `SERVD` directory:

```bash
# Navigate to project root
cd d:/SERVD

# Install root dependencies
npm install
```

### 3. Setup Environment Variables
Create `.env.local` inside `frontend/` by copying `.env.example`:

```bash
cp frontend/.env.example frontend/.env.local
```

Fill in the following credentials:
- `GEMINI_API_KEY`: Google Gemini AI Key
- `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY` & `CLERK_SECRET_KEY`: Clerk Auth Keys
- `STRAPI_API_TOKEN`: Strapi Full Access API Token
- `ARCJET_KEY`: Arcjet Rate Limiting Key
- `UNSPLASH_ACCESS_KEY`: Unsplash Developer Key

### 4. Database & Strapi Backend Setup
To configure the Strapi v5 backend with Neon DB PostgreSQL:

```bash
cd backend
npm install

# Setup backend environment variables (.env)
cp .env.example .env
```

Update `DATABASE_URL` in `backend/.env` with your Neon PostgreSQL connection string

Run Strapi in development mode:
```bash
npm run develop
```
1. Open `http://localhost:1337/admin` to create the Admin account.
2. Under **Settings -> API Tokens**, create a new token with **Full Access**.
3. Copy the token to `STRAPI_API_TOKEN` in `frontend/.env.local`.

## 🚀 Running the Application

To run the Next.js frontend application from `d:\SERVD`:

```bash
# From root directory
npm run dev
```

Or run frontend directly:
```bash
npm run dev:frontend
```

Open [http://localhost:3000](http://localhost:3000) in your browser to test the platform.
